GERIVO v1.7.13 — ATUALIZAÇÃO VISUAL

Para quem já executou o SQL corrigido da v1.7.12:
1. Preserve o arquivo .env.local e a pasta .git.
2. Substitua os arquivos da atualização na pasta do projeto.
3. Não há SQL novo para executar.
4. Apague a pasta .next.
5. Execute:
   npm install
   npm run build
   npm run dev
6. Teste Orçamentos, Pedidos de peças, Gerivo BI e Gerivo MASTER.
7. Somente depois faça o git push.

Para uma instalação que ainda não recebeu o módulo Pedidos de peças:
1. Execute a migration corrigida:
   supabase/migrations/011_v1712_optional_parts_orders.sql
2. A chave PARTS_ORDERS será adicionada desativada por padrão.
3. Ative o módulo pelo Gerivo MASTER somente nas empresas contratantes.

Não execute novamente as migrations 001 a 010 em uma base já atualizada.
