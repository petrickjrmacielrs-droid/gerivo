GERIVO v1.7.10 — ATUALIZAÇÃO

1. Faça backup da pasta atual e preserve .env.local e .git.
2. Substitua os arquivos pelo pacote da v1.7.10.
3. Apague as pastas .next e node_modules.
4. Execute npm install.
5. Execute npm run build.
6. Execute npm run dev e teste localmente.
7. Faça git add ., git commit e git push.
