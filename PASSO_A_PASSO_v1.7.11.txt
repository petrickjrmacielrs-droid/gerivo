GERIVO v1.7.11 — ATUALIZAÇÃO

1. Faça backup da pasta atual do Gerivo.
2. Preserve obrigatoriamente:
   - .env.local
   - .git
3. Apague as pastas geradas:
   - .next
   - node_modules
4. Substitua os arquivos pelo pacote da v1.7.11.
5. No Supabase SQL Editor, execute somente:
   supabase/migrations/010_v1711_groups_access_importer.sql
6. No terminal:
   npm install
   npm run build
7. Se o build concluir:
   npm run dev
8. Valide antes de publicar:
   - editar nome do grupo;
   - vincular um gestor a duas empresas/unidades;
   - cadastrar função Consultor de Serviços;
   - comparar unidades no BI;
   - ativar/desativar o módulo Importador Mobato/NBS;
   - replicar configurações entre unidades;
   - excluir somente uma empresa de teste.
9. Publique pelo Git:
   git add .
   git commit -m "Atualiza Gerivo para v1.7.11"
   git push origin main

ATENÇÃO SOBRE EXCLUSÃO
A exclusão definitiva remove a empresa/grupo e seus dados vinculados no Gerivo.
As identidades de autenticação do Supabase não são apagadas automaticamente, pois um mesmo usuário pode pertencer a outras empresas.
