# Testes v1.7.14.2

## Pedidos de peças

- [ ] Abrir pedido existente mostra **Editar pedido**.
- [ ] Editar pedido abre a tela ampla.
- [ ] É possível adicionar uma ou várias novas peças.
- [ ] Peça existente não pode ser apagada pela edição.
- [ ] Peça nova ainda não salva pode ser removida.
- [ ] Nova peça salva inicia como Pendente.
- [ ] Histórico registra a inclusão da peça.
- [ ] Correção de dados gerais gera histórico.
- [ ] Correção de código/descrição/quantidade/previsão gera histórico.
- [ ] Pedido totalmente reservado muda para reserva parcial ao adicionar nova peça pendente.
- [ ] Depois que a nova peça for reservada, a linha volta a verde quando todas estiverem reservadas.
