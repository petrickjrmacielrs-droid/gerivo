GERIVO v1.7.13.1 — HOTFIX DE USUÁRIOS E IMPORTAÇÃO

1. Preserve os arquivos:
   .env.local
   .git

2. Extraia a atualização sobre a pasta do projeto:
   C:\Projetos\mecflow

3. No Supabase SQL Editor, execute uma única vez:
   supabase/migrations/012_v17131_user_management_repair.sql

4. Confira o resultado final do SQL. As três colunas devem aparecer como true:
   job_function_ok
   custom_job_function_ok
   available_as_consultant_ok

5. Confira na Vercel as variáveis de ambiente:
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
   SUPABASE_SECRET_KEY

   SUPABASE_SECRET_KEY deve receber a chave secreta/service_role do projeto.
   Nunca use a chave publishable/anon nesse campo.

6. No terminal:
   cd C:\Projetos\mecflow
   rmdir /s /q .next
   npm install
   npm run build
   npm run dev

7. Testes mínimos:
   - Gestão > Usuários e acessos deve carregar a equipe.
   - Criar usuário em uma unidade.
   - Entrar com o novo usuário e a senha temporária.
   - Importar um PDF original do Mobato/NBS sem configurar reconhecimento visual.
   - Confirmar a prévia antes de adicionar itens.

IMPORTANTE
- Use npm install, não npm ci, nesta atualização. O pacote adiciona a dependência pdf-parse e o npm atualizará o package-lock.json.
- Imagens e PDFs escaneados ainda dependem do reconhecimento visual configurado pela empresa.
