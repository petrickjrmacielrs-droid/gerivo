GERIVO v1.7.14.2 — PACOTE ÚNICO DE LANÇAMENTO

Este pacote é cumulativo e já contém as alterações da v1.7.14, v1.7.14.1 e v1.7.14.2.
Use este pacote quando as atualizações 1.7.14.1 e 1.7.14.2 ainda NÃO foram aplicadas.

ANTES DE EXTRAIR
- Preserve o seu .env.local
- Preserve a pasta .git
- Faça backup do projeto atual

BANCO DE DADOS
Se ainda NÃO executou a migration da v1.7.14.1, execute no Supabase SQL Editor:
  supabase/migrations/013_v17141_parts_orders_workflow.sql

Não há SQL adicional exclusivo da v1.7.14.2.

DEPOIS DE SUBSTITUIR OS ARQUIVOS
cd C:\Projetos\mecflow
rmdir /s /q .next
npm install
npm run build
npm run dev

PRINCIPAIS ALTERAÇÕES INCLUÍDAS
- Central Gerivo MASTER separada da operação das empresas
- criação de grupo/empresa e replicação de configurações, módulos e usuários
- importador Mobato/NBS sem depender de grifo amarelo
- Pedidos de peças como módulo opcional
- campos configuráveis por empresa no módulo Pedidos de peças
- TAG visual G/C/I
- listagem operacional com cores por situação
- verde: todas as peças reservadas
- amarelo: reserva parcial
- vermelho: item em B.O.
- tela ampla para novo pedido
- acompanhamento após salvar
- histórico de status e comentários
- opção Editar pedido depois de salvo
- inclusão de novas peças em pedido existente
